Digital Infrastructure Access Mapping

A web-based application that displays access to digital infrastructure on a map.

Features
- Displays markers for cities with digital infrastructure access data
- Popups display city name and access level
- Uses Leaflet.js library and OpenStreetMap tiles

Technologies Used
- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap

Getting Started
1. Clone the repository: `git clone https://github.com/your-username/digital-infrastructure-mapping.git`
2. Open `index.html` in a web browser

How it Works
1. The map is created using Leaflet.js library and OpenStreetMap tiles.
2. Markers are added to the map for each city in the data, with a popup displaying the city name and access level.

Customization
- Add your own data points by modifying the `digitalInfrastructureData` array in `script.js`
- Change the marker icons or use different tile layers to customize the map

Requirements
- None, this is a client-side application that runs in a web browser

Future Development
- Add more data points and access levels
- Use different colors or icons for different access levels
- Integrate with other data sources or APIs
